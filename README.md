# Sales Performance Dashboard

# Project Overview

An interactive Power BI dashboard developed to analyze and monitor sales performance using data visualization and business intelligence techniques.

The dashboard provides insights into sales, revenue, profit, products, customers, and regional performance through interactive visualizations and filters.

# Project Objective

The main objective of this project is to transform raw sales data into meaningful business insights using Power BI.

The dashboard helps users:

- Monitor overall sales performance
- Analyze revenue and profit
- Identify top-performing products
- Compare regional performance
- Understand sales trends
- Make data-driven decisions

# Tools & Technologies

- Power BI
- Power Query
- DAX
- CSV Dataset
- Data Visualization

# Key Features

- Interactive KPI cards
- Sales and revenue analysis
- Profit analysis
- Product performance analysis
- Regional sales analysis
- Interactive slicers and filters
- Charts and visualizations
- Business performance insights
